# PolyclinicRegistration

Курсовой проект «Регистрация посетителей поликлиники». Приложение для записи к врачу и ведения журнала приёмов.

Откройте `PolyclinicRegistration/PolyclinicRegistration.csproj` в Visual Studio и запустите проект. Для сборки нужен .NET 10 SDK. Пароль для входа в журнал сотрудников — `111`.

Готовая сборка для Windows x64 находится в папке [bin/Release/net10.0-windows/win-x64](PolyclinicRegistration/bin/Release/net10.0-windows/win-x64). Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и запустите из этой папки `PolyclinicRegistration.exe`. Для этой сборки .NET отдельно устанавливать не нужно.
