# PolyclinicRegistration

Курсовой проект «Регистрация посетителей поликлиники». Посетитель выбирает врача и время приёма и получает талон. Сотрудник может найти и отменить запись. Демонстрационный пароль для входа в журнал — `111`.

## Запуск на Windows x64

Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив целиком и откройте `PolyclinicRegistration.exe` в папке [bin/Release/net10.0-windows/win-x64](PolyclinicRegistration/bin/Release/net10.0-windows/win-x64). Для этой сборки .NET отдельно устанавливать не нужно.

Для сборки из исходников откройте `PolyclinicRegistration/PolyclinicRegistration.csproj` в Visual Studio с установленным .NET 10 SDK.
